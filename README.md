## Semana 7 — Pulido funcional y UX
<!-- primera línea del resumen -->
Paginación, búsqueda simple y estado vacío agregados al listado.
<!-- segunda línea: los hallazgos de tu compañero y cómo los corregiste -->
Hallazgos de la UI review corregidos: 
Se añadió una barra de búsqueda que permite localizar los servicios de manera más rápida y sencilla. Además, se implementó un sistema de paginación que limita la visualización a 5 elementos por página, evitando que el listado se vea demasiado saturado. También se agregaron botones de navegación para avanzar y retroceder entre las páginas, mejorando la organización de los registros y facilitando la interacción del usuario con la interfaz. Por último, se incorporó un mensaje de estado vacío para informar cuando no existen registros disponibles o cuando la búsqueda no arroja resultados.
